### 🚀 Featured Project — Tamtrack

> An adaptive e-learning platform that learns from each student's mistakes and generates personalized courses.

**How it works:**
1. Student starts a course → AI generates content based on their level and filière
2. After each chapter → 3 adaptive QCM exercises
3. Wrong answers are stored and analyzed → next course focuses on those gaps
4. Student sees their weak point diagnosis before studying
